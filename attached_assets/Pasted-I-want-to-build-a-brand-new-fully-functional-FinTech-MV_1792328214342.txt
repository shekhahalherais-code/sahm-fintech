I want to build a brand-new, fully functional FinTech MVP called **SAHM | سهم**, starting from scratch.

## Product overview

SAHM is an AI-powered financial education platform designed to help beginners understand financial reports published by companies listed on Boursa Kuwait.

**Tagline:** افهم الأرقام قبل القرار

**English tagline:** Understand Before You Invest.

### Problem
Financial statements and disclosures contain complex accounting terminology and large amounts of numerical data. Beginners often struggle to interpret these reports and understand a company's financial performance.

### Target audience
Beginner investors in Kuwait, university students, and individuals interested in understanding the financial performance of publicly listed companies.

### Solution
Users upload a financial report in PDF format. SAHM extracts important financial information, explains it in simple Arabic or English, and presents the results through a visual dashboard with traceable references to the original report.

## MVP features — build ONLY these three

### Feature 1: Smart Financial PDF Upload & Extraction

- Allow users to upload a text-based financial report in PDF format.
- Validate file type and size.
- Extract company name, reporting period, revenue, net profit, and other clearly identifiable financial metrics.
- Show the original currency and units, including whether values are expressed in thousands or millions.
- Display page references for extracted values.
- Do not invent missing values.
- Clearly label unverified or unavailable information.
- Provide a review screen showing the extracted information.
- Store structured analysis data in MongoDB.
- Provide understandable error messages when extraction fails.

### Feature 2: AI Financial Explainer

- Explain financial metrics and accounting terminology in simple language.
- Support Arabic and English.
- Explain what each financial indicator means and why it matters.
- Ground all company-specific explanations in extracted report data.
- Display references to the original PDF pages.
- Do not generate unsupported claims.
- Do not provide stock predictions or buy/sell recommendations.
- Use a server-side AI API with keys stored securely in environment variables.

### Feature 3: Financial Dashboard & Downloadable Report

- Display financial metrics in clean cards.
- Include appropriate charts for available financial data.
- Compare two reporting periods only when comparable values are available.
- Clearly distinguish profit, revenue, assets, liabilities, and equity.
- Generate a simplified downloadable PDF report containing the extracted metrics, explanations, source references, and appropriate disclaimers.
- Never display fabricated example data as actual company data.
