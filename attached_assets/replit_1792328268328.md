# SAHM | سهم

## Problem
يواجه المستثمرون المبتدئون والأفراد المهتمون بسوق الأسهم في الكويت صعوبة في فهم التقارير المالية والإفصاحات المنشورة للشركات المدرجة في بورصة الكويت، بسبب كثرة الأرقام والمصطلحات المحاسبية وتعقيد عرض المعلومات. وهذا يجعل تقييم الأداء المالي للشركات وفهم نتائجها أمرًا صعبًا لغير المتخصصين، وقد يدفعهم للاعتماد على آراء الآخرين بدل فهم البيانات المالية بأنفسهم.

## User
المستثمرون المبتدئون في الكويت، وطلبة الجامعات، والشباب المهتمون بالاستثمار في بورصة الكويت، والأفراد الذين يرغبون في فهم الأداء المالي للشركات المدرجة دون الحاجة إلى خبرة متقدمة في المحاسبة أو التحليل المالي.

## Solution
سهم منصة FinTech تعليمية مدعومة بالذكاء الاصطناعي، تساعد المستخدم على فهم التقارير المالية للشركات المدرجة في بورصة الكويت. يرفع المستخدم تقريرًا ماليًا بصيغة PDF، فتستخرج المنصة البيانات المالية الأساسية وتعرضها في لوحة تحليل تفاعلية، مع شرح مبسط للمؤشرات والمصطلحات المالية بالعربية والإنجليزية، وإظهار مصدر المعلومات من التقرير الأصلي.

## Differentiator
يتميز سهم بتركيزه على المستثمر المبتدئ والسوق الكويتي، حيث يجمع بين قراءة التقارير المالية بالذكاء الاصطناعي، وتبسيط المصطلحات المحاسبية، وعرض المؤشرات المالية برسوم بيانية واضحة، مع دعم العربية والإنجليزية. لا يكتفي بعرض الأرقام، بل يساعد المستخدم على فهم معناها، مع الإشارة إلى مصدر كل معلومة وعدم تقديم توصيات شراء أو بيع.

## MVP features (build only these)
- 1. Smart PDF Upload & Financial Extraction: رفع تقرير مالي PDF واستخراج اسم الشركة والفترة المالية والإيرادات وصافي الربح والمؤشرات الأساسية المتاحة، مع إظهار الصفحات المصدرية والتنبيه عند تعذر التحقق من أي رقم.
- 2. AI Financial Explainer: شرح الأرقام والمصطلحات المالية بلغة مبسطة بالعربية والإنجليزية، مع أمثلة توضيحية وتوثيق المعلومات من التقرير، دون اختلاق بيانات أو تقديم توصيات استثمارية.
- 3. Financial Health Dashboard & Report: لوحة تفاعلية تعرض المؤشرات المالية والرسوم البيانية والمقارنات بين الفترات عند توفر البيانات، مع ملخص مالي مبسط يمكن تحميله بصيغة PDF.

## Vision (do not build yet)
أن تصبح سهم منصة رائدة في تبسيط المعلومات المالية للمستثمرين الأفراد في الكويت والخليج. مستقبلًا، يمكن تطويرها لربط إفصاحات الشركات المدرجة بمصادر بيانات مالية مرخصة، ومتابعة الشركات، وإرسال تنبيهات عند صدور تقارير جديدة، وإتاحة المقارنات بين الشركات والقطاعات، وتقديم أدوات تعليمية وتحليلية أعمق مدعومة بالذكاء الاصطناعي، دون أن تحل محل الاستشارة الاستثمارية المتخصصة.

## Stack
- Frontend: React with Vite
- Backend: Node.js and Express
- Database: MongoDB Atlas with Mongoose
- Payments: Stripe test mode only, if needed

## Rules
- Build one feature fully, then the next.
- Small steps. Explain each change.
- Never put secrets in code. Use Replit Secrets or .env.
- Do not add features that are not in the MVP list.
